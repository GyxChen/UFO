主窗口「两级 tab」三套方案

一级 tab = 悬浮窗设置 / Agent 状态灯 / 后续每个有设置页的组件各占一个； 二级 tab = 该页自己的分区，避免状态灯那一堆配置（行为 / 窗口格子 / 当前会话 / 信息卡拓展 / 会话记录）挤在一条滚动里。三套只差「二级长什么样」，一级都是下划线横条 + 内容区不变。

方案 A · 双层横条推荐

一级下划线横条下面再来一条更矮的条，二级用胶囊（浅绿底 + 翠绿字）选中。

  • 两级都用横向 tab，位置固定、切换最快；胶囊与下划线外观不同，不会看成两条一样的条
  • 分区再多也只是换行，不挤内容；垂直方向多占 36px

方案 B · 一级横条 + 二级左侧竖排

选中一级后，内容区左边出现一列竖排二级导航，选中项带左侧翠绿竖条。

  • 最像「设置中心」，分区多、名字长也不挤；右侧内容区独占高度
  • 窄窗（800px）下内容区只剩约 620px，双列布局的面板会更早塌成单列
打开 →

方案 C · 一级横条 + 二级分段控件

不加第二条导航，页面标题右侧放一个分段控件选分区，最省垂直空间。

  • 视觉最轻，空间全留给内容；分区只有 2–3 个时最舒服
  • 分区到 5 个（状态灯就是 5 个）就偏挤，且和表单里的分段控件样式重复，容易混淆
