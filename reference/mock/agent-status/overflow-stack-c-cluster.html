方案 C · 微型灯阵语义最直白

被折叠的灯不"抽象"成色块，而是原样缩小排进溢出格：沿对角线叠 3 盏真实灯点（带白边、带光晕、 该闪的照样闪），右下角沿用「平台图标徽章」的位置与做法放一个 +N 圆片。 用户看到的不是"一堆颜色"，而是"后面还压着三盏灯"。

← 四套方案索引 A 实心堆叠 B 分片环 C 微型灯阵 D 涟漪同心

设计要点

  • 最多 3 盏：与其它方案同一个上限；前排（左下）放最需要注意的那盏（红 → 黄 → 绿）。
  • 重叠靠"抠边"读：每个小灯点外圈一道窗口底色（box-shadow 实心环）， 后面的灯被压住的地方露出一条深缝 —— 和平台图标徽章从灯点上"抠"出来是同一招。
  • 闪烁保留：折叠里的完成态/等待态灯照样闪，用户扫一眼就知道后面有没有刚跑完的。
  • 数字落在徽章位，与普通灯的 provider 徽章同一个位置：视线不用重新找。
  • 代价：三盏小灯 + 数字，是四套里元素最多的一套，格子小（≤32px）时必须降级成一盏。
