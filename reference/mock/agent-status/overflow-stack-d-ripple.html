方案 D · 涟漪同心小格子里最醒目的灯色

溢出格前半是一盏真正的灯 —— 折叠里最需要注意的那盏（红 → 黄 → 绿），它的颜色、描边、光晕、闪烁全按真灯渲染； 后面 1–2 圈同心细环按次优先级的灯色向外淡出，右下角仍用徽章位放 +N。 一眼看到的是「一盏灯 + 它后面还有几圈」，而不是「一个色块 + 一个数字」。

← 四套方案索引 A 实心堆叠 B 分片环 C 微型灯阵 D 涟漪同心

设计要点

  • 环数 = min(折叠数, 3) − 1：折叠恒 ≥ 2，所以永远至少一圈涟漪，也永远不超过两圈。
  • 灯色最醒目：前面的灯占格 62%（A 的深盘只有 72% 且被 +N 占满），45px 下这就是四套里最容易读出颜色的一套。
  • 涟漪用「本色 + 透明度」的细环，不是实心同心圆：太实会变靶心，抢掉前面那盏灯。
  • 环的次序按注意力优先级向外排（红 → 黄 → 绿），越远越淡。
  • 风险：一盏 红灯 在最前面容易被误读成「这一格对应的会话在报错」，而它其实是折叠里的某个会话 —— +N 徽章与缩略的灯径就是区分手段（普通灯是 80% + 平台图标徽章）。
