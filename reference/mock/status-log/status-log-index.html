已拍定的规格（不再变）

项约定
一个 switch 管全部 关闭 = 完全不记；打开 = 明细级 + hook 侧同记。原来的四档分段控件与独立「hook 侧也记」开关都不再出现在界面上 —— 一个行为只留一个入口。 Rust 侧 LogConfig 的字段结构保留，前端把 level 与 hook_enabled 当成一个开关一起写：开 → {level:'verbose', hook_enabled:true}，关 → {level:'off', hook_enabled:false}。全新安装默认关。
关掉之后还剩什么 「会话记录」列表与「记录详情」里的状态 / Endpoint / Token / 最后活动 / 创建时间 / 最近提问全部照旧 —— 提问采集与 session-records.db 是加日志之前就有的独立功能。 hook-debug.log 归这个开关管：关了就什么都不写。
灯色字要染色 链路文字里的「黄」「绿」按状态灯色染（--ufo-warn / --ufo-accent），扫一眼就知道说的是哪个灯；但用户提问原文里的字不染（那是引文，不是日志值）。
展开交互 详情里的条目默认只查 get_status_log({ key: 选中会话, limit: 3 })（第一条做结论行、后两条做摘要，整块约 127px，实测 1000px 宽下右列 455/455 不产生滚动）；条目行尾两个动作同高对齐（实测 top/bottom 差 0）：「导出本会话」与一个图标钮。图标钮打开左右两栏整窗浮层（实测左流水 409px / 右完整信息 553px，右栏 719/581 自己滚）。两处导出是同一命令的不同范围，不是重复入口。 ⚠️ 浮层外壳照 .jse-modal 那套 CSS 类（main.css:1149：实色铺满、44px 标题栏、「完成」+ Esc），但 ScriptEditorModal.vue 没有 slot（模板写死 ScriptEditorFrame 与 aria-label），组件本身复用不了 —— 待定：给它加默认 slot，还是新写一个约 30 行的 overlay 组件共用类名。
左列会话卡片 本轮按批注改成定高 + 顶对齐：min-height: 52px（实测渲染 60px，三行等高），提问一律一行省略号收尾（真实现里把 .sr-list__prompt 的 line-clamp-2 换成单行）。行内与列表两处都要 align-content: start，否则默认 stretch 会把行撑开。
平台图标 列表行用各自的真图标（mock 直接引 src/assets/{claude,codex,qoder}.svg，不另画假的以免漂移）；mono 那两张走 --ufo-mono-icon-filter（深色主题下是 none）。
一行日志的内容 时间 · 环节徽标 · reason + 摘要。左侧色条只表达三档：绿 = 灯真的变了、黄 = 被拒 / 被丢 / 被顶回、红 = 出错或摘灯。环节与理由都用文字表达，不只靠颜色。
贯穿 id trace_id 由 hook 生成 <pid>-<纳秒>，同时是 inbox 文件名与关联键。不用 payload 里的 event_id（外部可控串，拿来拼名字就是路径注入）。没有 trace 的行（如上游反查、日志自身维护）不可展开。
过滤与展开 浮层是左右两栏主从（与信息卡拓展 / 会话记录同一套语言，实测 1000px 下左 409 / 右 553）：左栏 = 本会话全部流水（key 过滤，新→旧，默认跟随最新），过滤条件只剩三个 —— 环节下拉、「只看被拒 / 被丢」、「暂停跟随」；「只看这一条信号」那颗 chip 已删，也不在行下面就地展开。点左栏某一行 → 右栏显示那条记录的完整信息：LogEntry 全字段（seq / writer / stage / reason / trace_id / provider / session_id / key / actor / kind / phase_from→phase_to / sequence / watermark / revision）+ detail + 同 trace_id 的其它行 + 磁盘上那一行 JSONL 原文。右栏内容高于一屏，自己滚（实测 719 / 581）。认不出的过滤取值不匹配任何东西（而不是静默变全量）。
导出 「导出当前条件」→ 系统另存为选路径 → export_status_log({ path, query })。校验：绝对路径、扩展名 jsonl/log/txt、拒绝写进正在 tail 的日志目录内。取消即不发命令。风险告知常驻：导出内容含提问原文。
数据量 面板读内存环形缓冲（5000 条），"导出你看得见的那些"；更早的按 before_seq 翻页。浮层底部常驻一行显示日志目录与被挤掉多少条。
后端复用 Rust 侧整套（22 阶段 / 68 理由、JSONL 落盘与轮转、内核具名裁决、hook 每次调用恰好一行）从被 git reset 摘掉的提交里捞回，只改四处：默认档位、导出签名、命令入参、dialog 插件。前端按这版版面重写。
