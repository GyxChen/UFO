03插件的 tooltip 有两种：自己的独立信息卡 与 插进别人的卡里一块

弹哪一张由悬停目标属于谁决定（外壳只走注册表：resolveTooltipDefinition 拿目标所在模块的 tooltip 声明），插件两条都能要，互不冲突： 3a 悬停插件自己的格子 → 弹这个插件自己的卡，尺寸由插件按 size 声明（可以是按悬停目标算的函数），外壳夹进工作区； 3b 悬停agent 的灯 → 在 agent 卡尾部追加一块，虚线分隔 + 极小来源标注，最多 3 行（MAX_FIELDS 与窗高同源）。 ⚠️ 两条都受同一条约束：没内容就不许弹（hasContent 为假时外壳直接不弹，避免一块空卡糊在屏幕上）； 独立卡里屏幕上不再叠一层标题栏，来源只写进行首那枚小徽标。

06配套口径（不是 UI，但决定上面几块能不能落地） 
// plugins/balance-board/plugin.json —— 外壳只认这一份声明
{
  "id": "balance-board",
  "entry": "main.js",
  "surfaces": {
    "cell": 2,
    // 两种 tooltip 是两条独立声明，可以只给一条、也可以两条都给
    "tooltip": { "own": true, "size": [340, 260] },
    "extension": { "into": "agent-status", "maxRows": 3 },
    "settings": true
  },
  "permissions": [ "http", "storage" ],
  "hosts": [ "api.example.com" ]
}
// main.js —— 跑在 QuickJS 沙盒里，能力只有注入的这些
ufo.cell({
  async draw(ctx) {
    const r = await ufo.http.get('https://api.example.com/v1/balance', {
      headers: { Authorization: `Bearer ${ufo.secret('TOKEN')}` }
    })
    ufo.log('info', '轮询完成', { ms: r.ms })   // ← 04/05 那三行日志的唯一来源
    return { k: '余额', v: ufo.format.money(r.json().balance) }
  },

  // 3a：悬停「自己这块格子」→ 插件自己的信息卡（尺寸见 manifest，外壳夹进工作区）
  tooltip(ctx) {
    return {
      title: '账户额度',
      rows: [ { label: '余额', value: ctx.v }, { label: '配额', value: ctx.quota } ],
      meter: ctx.quotaPct,
      hasContent: () => ctx.v != null   // 假 = 整卡不弹，不留一块空的
    }
  },

  // 3b：悬停 agent 的灯 → 往那张卡尾部追加一块（最多 3 行，受 MAX_FIELDS 预算）
  extension(ctx) {
    return [{ label: '余额', value: ctx.v }, { label: '配额', value: ctx.quota }]
  }
})

红线（沿用现网约束，一条都不放宽）：插件没有 fs / net / child_process，也没有模块加载器，出网只走注入的 ufo.http 且必过 validate_http_url； 密钥只在闭包里按名取，值不落盘、不进日志；外壳代码里不得出现插件 id（注册表与 src/windows/index.ts 是唯一允许点名的组合根）； ufo.log 只进该插件自己的环形缓冲（200 条），关调试即零写盘；日志里的明文落盘风险与转灯日志同级，导出前要在这一刻提示一次； 安装 = 校验 manifest + 落到 app-data/plugins/<id>/，卸载两步确认，路径一律过 validate_export_target 那类白名单，不接受未校验输入拼路径。
